# Tamkeen Helpdesk Pro 🛠️

**Version:** 16.0.6.0.0  
**License:** LGPL-3  
**Author:** Akram
##  Overview
**Tamkeen Helpdesk Pro** is a fully featured Support Ticket Management System designed for Odoo 16. It streamlines the customer support workflow by integrating SLA management, automated assignments, and a user-friendly customer portal.

This module is designed to enhance team productivity and improve customer satisfaction through automated email templates and feedback surveys.

##  Key Features

###  Ticket Management
* **Multi-Team Support:** Organize support into specific teams.
* **Auto-Assignment Rules:** Automatically assign tickets based on predefined criteria.
* **Canned Responses:** Speed up replies with pre-written templates.

###  Performance & Analytics
* **SLA Management:** Track Response and Resolution times effectively.
* **Advanced Dashboard:** Visual analytics for team performance and ticket status.
* **Time Tracking:** Monitor exactly how long each ticket takes to resolve.

###  Portal & Communication
* **Website Integration:** Customers can submit and track tickets directly from the portal.
* **Email Automation:** Includes 5 ready-to-use email templates for status updates.
* **Customer Feedback:** Integrated Satisfaction Surveys and Rating System.

## ⚙️ Dependencies
This module relies on the following Odoo standard modules:
* `base`
* `mail`
* `portal`
* `website`
* `web`
